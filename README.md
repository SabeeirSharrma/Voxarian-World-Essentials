# Voxarian World Essentials

Essential resources for the Voxarian World modpack

A lightweight client-side Fabric mod that customizes the Minecraft title screen
with Voxarian World branding and removes the splash text.

## Features
- Custom title screen logo
- Client-side only
- Compatible with Fabric modpacks
- Dependency for all custom Voxarian World mods

## Requirements
- Minecraft 1.20.1
- Fabric Loader
- Fabric API

## Compatibility
✔ Sodium  
✔ Lithium
✔ Iris  
✔ Modrinth App 

## Notes
This mod is client-only and does not need to be installed on servers.
